ℹ️ How this actually works

Every time you add or remove a delivery, this page calls a live API running Dijkstra's algorithm at smart-delivery-routes-live-api.onrender.com, on top of real road data for Port Harcourt pulled from OpenStreetMap. It calculates the true shortest legal driving distance from the restaurant to every delivery spot in one pass. The server can take up to a minute to respond if it's been idle and is waking back up. If live map data can't be loaded, the API automatically falls back to a demo grid so it still works — you'll see a warning badge above if that happens.
