ℹ️ How this actually works

Every time you add or remove a delivery, this page calls a live API running Dijkstra's algorithm at smart-delivery-routes-live-api.onrender.com. It calculates the true shortest legal driving distance from the restaurant to every delivery spot in one pass — respecting one-way streets instead of assuming you can drive as the crow flies. The server can take up to a minute to respond if it's been idle and is waking back up.
